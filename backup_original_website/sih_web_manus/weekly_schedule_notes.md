# Weekly scheduling display rule

Every source request now records its department-specific preferred day, date, and UTC work interval. These are preferences that make the coordination challenge visible; they are not presented as the final scheduled closure.

Each optimized result instead displays one selected **Common work day** and **Shared time** for all work included in that block. In the current sample plan, the selected common date and time are taken from the optimized block’s scheduled window on 23 August 2026. The request table and initial desktop verification render the new weekly-preference column successfully.
